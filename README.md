## 📊 Featured Project

### 🇨🇦 [Canadian City Intelligence](https://github.com/abdn-fz/canadian-city-intelligence)

An applied data science project exploring how major Canadian cities have evolved across **population, employment, unemployment, crime, cost of living and housing**.

**Cities covered:**

Montréal · Ottawa-Gatineau · Toronto · Winnipeg · Regina · Saskatoon · Calgary · Edmonton · Vancouver

### 🔎 Questions explored

* How have major Canadian cities changed over time?
* How does population evolution differ between cities?
* How have unemployment and labour-force indicators evolved?
* How has the cost of living changed?
* How have housing prices evolved?
* How do these indicators compare across cities?
* How does **Ottawa-Gatineau** fit into the broader Canadian picture?

### 🧰 Pipeline

`CSV Data` → `Python EDA` → `Data Cleaning` → `SQL` → `Data Integration` → `Power BI` → `Machine Learning`

**Tools:** Python · Pandas · SQL · Power BI · Microsoft Fabric · Machine Learning

**Status:** 🔄 In progress
